# 指定文件夹恢复 · 2026-11-27

恢复页中的「恢复到指定文件夹」现可选择目录并执行。原音频复制到所选位置新建的 Music Center 文件夹，恢复事务会更新曲目路径；每首曲目使用独立子目录，以容纳不同曲目的同名文件。源文件保持原位。

## 实际验证

- Release 构建、严格签名验证、工程配置检查及 Git 差异检查通过。
- 临时曲库成功复制 3 首音频，逐字节核对内容；验证路径重开后持久化、同名音频独立存放、播放列表重复条目及 ID 保留。
- 目标已有 Music Center 项目时拒绝覆盖。确认后才出现同名目标时也拒绝，原目标内容保留。
- 原音频缺失、目标位置失效和设置写入失败时，当前数据库及设置保留。本次临时音频及发布目录清理验证通过。
- 旧备份、原地址恢复、损坏备份拒绝及自动恢复前备份验证通过。
- 通过真实菜单操作验证两种地址选项、目录选择、空目标时禁用下一步、确认页目标、成功及错误返回。截图的紧凑窗口允许滚动。

## 文件格式与边界

现有 .musiccenterbackup 只保存记录和设置。指定目录恢复需要从备份记录的原路径读取音频，因此原音频必须仍可访问。新副本发布完成后才应用数据库，应用失败时清理本次副本。恢复前自动备份保留原路径信息。

使用隔离 QA 曲库验证，未替换已安装应用，也未更改实际用户曲库。
