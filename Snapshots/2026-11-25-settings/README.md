全部设置页共用平直矩形下拉、金色选中标记、Windows 样式滚动条与按钮。面板保留 710 点宽、最高 690 点高；空间不足时缩短内容视口，底部按钮固定显示。系统原生滚动条明确禁止显示，避免系统滚动条偏好引入第二根滚动条。

MP3 码率为 320/256/224/192/160/128/112/96 kbps；AAC 和设备传输码率为 320/256/192/160/128/96/80 kbps。切换格式时不适用的码率显示 128 kbps，期间未重新选择码率时，回到原格式仍可恢复原选择。WAV/FLAC 的容量为 Windows 界面参考估值，不是实际编码大小保证。

## 实际验证

- Xcode Release 完整应用构建成功；本地签名及 `codesign --verify --deep --strict` 通过。
- 独立设置应用运行了 `Tests/SettingsPreferencesSmoke.swift`：旧配置缺字段读取、112/224 kbps、格式切换回退、旧语言名称兼容、文件夹和目标路径、384 kHz、输出设备标识保存重开、草稿隔离均通过。

本次完成的是设置页视觉与草稿交互。Gracenote/12 Tone Analysis、网络共享、自动文件夹监视、Sony 更新及清除类业务尚未接入。清除/检查按钮显示支持范围提示，不删除用户数据或联网执行更新。输出位深与跳过选项保存界面状态；采样率作用于现有 Mac 播放处理，硬件位深由 macOS 管理。
