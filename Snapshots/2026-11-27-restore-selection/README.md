# 恢复选择页修正 · 2026-11-27

此前恢复页将日期和备注放在选中有效备份后的条件分支，导致未选文件时只剩选源行。本次补回常驻信息区域、恢复地址控件与原版提示，恢复面板改用 640 点宽高的常规尺寸，紧凑窗口允许内容滚动。

截图来自独立临时曲库的真实生产视图，顶端为 QA 工具栏。Release 构建和严格签名通过。真实工具菜单进入后验证空日期和备注、地址控件、禁用的下一步；旧备份、损坏拒绝、日期备注预览、正常恢复及设置写入失败回滚均通过。取消按钮可返回主菜单。空文本辅助功能标签曾引发系统递归崩溃，去除新增标签后，同一路径复测通过。

指定文件夹恢复音频仍未实现，该选项和对应浏览按钮明确禁用。当前可执行流程为恢复当前曲库并沿用备份中原音频路径，因此此快照仅完成选择页信息遗漏修正，不宣称全部 Windows 功能和状态已一比一还原。

未改动实际用户曲库，未覆盖现有安装的应用。
