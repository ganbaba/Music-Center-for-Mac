## 随机播放与循环

工具栏左侧和「控制 → 随机播放」共用状态。开启时，当前曲目移到队首，其余曲目重新排序，播放位置和暂停状态保留。关闭时还原进入队列时的顺序。随机播放开启时，切换循环方式会以当前曲目为首重新排队。

单曲循环在曲目自然播完时重播，手动切歌仍按队列前进。全部循环到达末尾后开始下一轮，随机开启时会重新洗牌。关闭循环时末首播完清除当前曲目，保留队列供重新播放。参考图见 `Reference/shuffle-*.png`。

## 导入播放列表文件

从「文件 → 导入播放列表…」选择一份 `.m3u` 或 `.m3u8`。播放列表以文件名命名，使用文件中有效曲目的顺序。可读取相对于列表文件的路径、macOS 绝对路径及本地 `file:` URL。已在曲库中的文件复用已有曲目；重复路径按原顺序保留为独立列表条目，可分别移动、移除或选择播放。缺失文件、无法解析的 Windows 绝对路径、网络路径及远程 URL 会被跳过。成功后弹出「导入完成。」并停留在原页面。全部条目无效或选择的是 HLS 流媒体列表时，曲库报错并保留原有数据。

Windows 2.7.4 对照图见 `Reference/playlist-import-windows-completion.png` 和 `Reference/playlist-import-windows-detail.png`。旧曲库在打开时会自动升级，已有列表的顺序会保留。

两种格式均接受 UTF-8。`.m3u` 另接受带 BOM 的 UTF-16 和 Windows-1252。Windows 的格式和本地文件要求见 [Sony 导入指南](https://www.sony.com/zh-cn/electronics/support/sound-bars-home-theater-systems-sound-bars-surround-speakers/ht-rt5/articles/00198866)。

## WALKMAN 传输和设备管理

本机挂载为 WALKMAN 的外置卷会显示型号、位置和容量。设备发现和型号读取在后台执行，可移动卷权限提示和读取延迟不会阻塞主界面。型号来自卷根目录的 `default-capability.xml`。在歌曲页选择曲目、在专辑页选择整张专辑，或在播放列表详情选择条目后，点金色箭头进入传输预览。预览列出新文件、相同内容、同名冲突和不可用的源文件；点「开始传输」后写入设备。已存在且内容相同的文件会复用，同名不同内容的文件会保留并报告冲突。整张专辑按艺术家、专辑和碟号组织，播放列表生成 UTF-8 M3U，重复条目保留且共用设备上的音频文件。

设备传输设置的正常模式保留支持的原始格式，CAF 等需要转换的本地格式转为 AAC。自动指定模式把所选曲目转为 44.1 kHz 双声道 AAC，使用所选码率，保存标题、艺术家、专辑、曲号、碟号和封面。勾选删除转换文件时，转换文件在完成或关闭预览后清理；取消勾选时按源文件内容、标签和转换参数保留本地缓存。

「管理设备中的歌曲」读取真实 MUSIC 目录，点文件夹逐层进入，用返回箭头回到上一级。选中的歌曲可导回用户选择的计算机文件夹，并登记到本地曲库；删除设备歌曲需要确认。删除前会复核所选文件，文件已有变化时要求刷新。原始本地曲库和计算机上的源音频独立保留。

传输可以取消，已完成的文件会保留，重新检查后重试会复用这些文件。设备断开时停止操作，重新连接同一卷后可以重新检查。真机已验证原文件传输、AAC 和重复 M3U、导回登记、目录导航、确认删除、正常卸载和重新挂载。专用挂载卷验证了部分传输后的卸载、重挂和重试。设备固件重新索引与设备端实际播放需要在 WALKMAN 本机继续验收。

## 曲库备份与恢复

从「工具 → 数据备份」打开向导。查看预计大小，选定保存文件夹，填写备份名称和可选备注，然后确认开始。保存期间可以请求停止；向导会显示保存结果，遇到同名项目时保留原文件。生成的 `.musiccenterbackup` 包含曲库记录、播放列表、播放历史、设置、备份时间和备注。音频文件仍通过原路径引用。

从「工具 → 恢复备份数据」选取 `.musiccenterbackup`。向导会显示备份日期、曲目数与备注。旧备份没保存日期或备注时，这两项会显示为「未记录」。确认覆盖当前曲库、播放列表、历史和设置后，应用会再次核对文件并保存一份 `Before Restore` 备份，再恢复数据。恢复完成或应用备份失败时，向导会显示这份恢复前备份的位置。

当前恢复目标为页面显示的 Mac 曲库目录。音频继续引用备份记录中的路径，指定文件夹恢复音频尚待实现。

## 音频导出、CD 和专辑查询

在歌曲菜单选择「编辑歌曲 → 导出 WAV」或「导出 FLAC」，再选择目标文件夹。遇到同名文件时自动追加编号。FLAC 使用 macOS 的无损编码器，并保存常用曲目信息。

打开侧栏「CD」可读取 macOS 已挂载的音频 CD。选中曲目或整张导入，文件复制到所选文件夹后登记到曲库。CD 导入设置提供光驱选择、插盘操作、WAV／MP3／AAC／FLAC、80 分钟容量估算和自动弹出。AAC 可选 320、256、192、160、128、96、80 kbps；MP3 可选 320、256、224、192、160、128、112、96 kbps。MP3 需要带 libmp3lame 编码器的 FFmpeg。插盘默认无操作，可设置自动播放，或选择目标文件夹后自动导入。校验模式在转换前复制并比对光盘源文件。本机未连接光驱，导入流程使用 AIFF 测试文件验证。

「工具 → 批量转化ATRAC」使用已有的 FFmpeg 解码 OMA、AA3 或 AT3，再导出 FLAC。当前主机没有 FFmpeg。

CD 页的「查找专辑信息」继续使用公开的 MusicBrainz API，点击搜索会发送输入的专辑名称，并可在确认匹配后应用信息。歌曲菜单已还原为 Windows 的「获取未知属性」，目前说明 Gracenote 服务未接入，不把手动查专辑冒充自动识别。Sony 软件更新、DSEE HX 音频处理和数据库共享还未接入。

应用启动时从系统挂载列表识别 WALKMAN 和 CD。设备文件读取从「访问 WALKMAN」或打开 CD 页面开始。
