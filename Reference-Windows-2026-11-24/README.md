# Music Center for PC — Windows 实机 UI Reference

采集日期：2026-11-24（Asia/Hong_Kong）。来源为已连接的 Lucas Windows 远程桌面，Music Center for PC **2.7.4，中文界面，Windows 11 专业版**。

本目录含 **209 张独立文件的本轮实机截图**，原图合计 62.6 MiB。没有混入旧 Reference、Mac 重建界面或生成图片。

## 浏览方式

- 用浏览器打开 [截图目录](index.html)：可按分类与关键词搜索，点击缩略图打开原图。
- [覆盖与补拍清单](COVERAGE.md)：已拍范围、条件限制及未触发操作。
- [逐项计划核对表](capture-plan.csv)：原先 156 项计划与实机对应文件。
- [原图索引](capture-index.json)：每张图的标签、时间、来源文件名、原图尺寸和 SHA-256。
- `capture/`：原图；`thumbnails/`：仅供目录展示的缩略图；`overview/`：分类联系表。

## 使用原图时注意

原图为桌面工具返回的 **JPEG**，逐字节保存，未缩放、裁切、补画或重新压缩；本次不是无损 PNG 采集。多数原图为 2732 × 1536，精确尺寸逐图见索引。缩略图与联系表是另存的派生预览。

原图包含 Mac 的 Lucas 窗口栏、Windows 任务栏，以及远程环境产生的蓝色指针光晕。这些不是 Music Center 控件。Windows 文件/文件夹选择器属于系统界面；防火墙请求放在 `09-environment`，已取消授权。

同一设置页的顶部、底部及下拉展开均分别保留。未展开的文字、灰色禁用状态、空光驱/设备列表均按本机实际呈现记录；不能据此推定其他设备或歌曲格式下的所有条件界面。

## 本轮状态与操作

经用户允许创建的示例播放列表 **`ui 截图参考`** 引用原有 4 首 FLAC 歌曲，保留用于后续 UI 对照；未新增音频文件。

属性修改、设置页的临时选项、导入/导出/备份/恢复选择器均取消；没有保存歌曲标签、导出文件、执行备份或恢复，也没有授予 Windows 防火墙权限。截图期间播放过现有歌曲，最近播放等历史可能更新。

采集后恢复：白色配色、中号文字、标准列表间距；均衡器关闭并选民歌；DSEE HX 开启；DirectSound 标准输出；音量 100%、非静音；随机播放关闭、重复全部。播放器当前未载入歌曲，界面停留新添加的网格。
